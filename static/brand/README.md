# QBO Timesheet brand assets

An open clock completed by a check: recorded time reviewed and ready, in the existing blue and charcoal. Original artwork, separate from the QuickBooks corporate mark.

## Files

- `logo-mark.svg`: transparent, editable vector symbol for light surfaces.
- `logo-mark-light.svg`: transparent symbol for dark surfaces.
- `logo-lockup.svg` / `logo-lockup-light.svg`: symbol and outlined wordmark; no font dependency.
- `logo-mono-dark.svg` / `logo-mono-light.svg`: one-color versions for printing or constrained uses.
- `app-icon.svg`: full-bleed square icon master with a 72% symbol scale. Native OS applies its own corner mask.
- `app-icon-1024.png`: opaque RGB native/store icon export.
- `icon-192.png` / `icon-512.png`: full-bleed web-install exports; the symbol fits inside the maskable safe area.
- `apple-touch-icon.png`: opaque 180px home-screen icon.
- `favicon.svg`, `favicon.ico`, `favicon-16.png`, `favicon-32.png`: optically larger browser-tab variants.
- `logo-mark-512.png`: transparent symbol export.

## Use

Keep the symbol’s proportions. Prefer the mark below a 120px lockup width; browser tabs use the dedicated favicon. Leave at least 8/64 of the symbol width around it. Use the light variant on a dark background, and avoid recoloring individual pieces. Native app icons use the full square, without baked corner rounding. Existing company/report logos and UI colors retain their separate roles.

Primary `#2879C2`; accent `#4C9BE8`; dark `#12161C`; paper `#E6EBF1`.

Symbols are original vector artwork created for this application. Wordmarks are outlined; no fonts, remote images, scripts, embedded bitmaps or external resources are required. SVG masters are the source of truth. Re-export at exact target dimensions in an SVG renderer; flatten native PNGs to RGB. This asset set does not assert deployment or app-store distribution.
